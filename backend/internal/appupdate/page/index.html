How to install Jinsi ya kusakinisha

  1. Tap the green button above.Bonyeza kitufe cha kijani hapo juu.
  2. When the download finishes, tap Open.Upakuaji ukiisha, bonyeza Open.
  3. If the phone asks, allow installing from this app (Chrome), then press Back.Simu ikiuliza, ruhusu kusakinisha kutoka Chrome, kisha rudi nyuma.
  4. Tap Install (or Update).Bonyeza Install.
  5. Open DairyGo and log in.Fungua DairyGo na uingie.

If this page opened inside WhatsApp, tap ⋮ and choose Open in Chrome first.

If it does not work Kama haifanyi kazi

"App not installed" or "conflicts with an existing package"
Remove the old DairyGo first: Settings → Apps → DairyGo → Uninstall. Then install again. This is needed only once, when moving to version 1.4. Your records are kept on the server; you only log in again. Ondoa DairyGo ya zamani kwanza, kisha sakinisha tena. Rekodi zako ziko salama.

Updates Masasisho

From version 1.4, DairyGo tells you when a new version is ready. A green bar appears in the app; tap Update. You can also check in More → App version. You will not need to download it from WhatsApp again.

Kuanzia toleo 1.4, DairyGo itakujulisha toleo jipya likiwa tayari. Bonyeza Update ndani ya programu.
